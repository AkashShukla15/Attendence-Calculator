# Attendence-Calculator
A simple and responsive Attendance Calculator built using HTML, CSS, and JavaScript. This tool helps students easily track their attendance percentage and determine how many classes they need to attend or can skip to maintain a desired attendance level.

# Features

*  Calculate current attendance percentage
*  Add attended and missed classes dynamically
*  Set a target attendance percentage
*  Know how many classes you can bunk or need to attend
*  Instant results with a clean and responsive UI

# Tech Stack

* **HTML** – Structure of the application
* **CSS** – Styling and responsive design
* **JavaScript** – Logic and calculations

# Preview

A simple and intuitive interface where users input:

* Total classes conducted
* Classes attended
* Desired attendance percentage

…and instantly get actionable insights.

# How It Works

1. Enter the total number of classes held
2. Enter the number of classes attended
3. Set your desired attendance percentage (e.g., 75%)
4. The app calculates:

   * Your current attendance
   * Classes you can miss OR need to attend


# Use Cases

* Students tracking college/school attendance
* Avoiding attendance shortages
* Planning safe leaves or bunks
